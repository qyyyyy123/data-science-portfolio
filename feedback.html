What the review changed

One standard, applied to all six figures

Her task 2 was answerable for the map she happened to open. Applying the same question to the rest of the page showed that only two of the six captions actually stated their axes; the other four described the finding and left the reader to infer what was plotted. Since “axes and units” is exactly what the marking rubric asks for, that was a real gap and not a stylistic preference.

Before

“Figure 3 — the morning tilt reverses. Eight 30-minute slots. The share of net-source fences falls from 47.8 % …”

After

“Figure 3 — the morning tilt reverses. Eight 30-minute slots, one panel each. In every panel: x-axis = longitude (degrees), y-axis = latitude (degrees), colour = tidal index (unitless, −1 to +1) …”

All six captions on the project page now name their x-axis, their y-axis and the unit of each. No number changed.

One suggestion I declined

Suggestion (mine, during self-review): smooth the growth curve in the Netflix chart, because it “looks like a decline” at the end.
Decision: declined. The apparent decline is the dataset's truncated final year — its last entry is 2021-09-25. Smoothing would hide the one thing that chart is most useful for: check the boundary of a dataset before reading a trend into it. Recorded here rather than quietly dropped, because “it would look nicer” is not a reason to make an analysis worse.

Responsible sharing

Checks performed before publishing

Nothing sensitive is exposed

  • No passwords, API keys, tokens or .env files, at any point in the history of either repository
  • No personal data: no email addresses, phone numbers or student IDs in file names or content
  • The bike-share data is event-level with no rider identifiers
  • No restricted or licensed dataset is re-hosted

Third-party data stays third-party

  • The bike-share archive is CC BY-NC 4.0: linked by DOI and hash-verified, never committed
  • Only derived, aggregate artifacts are published, with the licence stated in the README
  • The Netflix extract is a public snapshot, committed with its notebook and attributed
  • Code is MIT; my own figures and reports are CC BY 4.0

Testing

What was checked before submission

  • Every page opens — index.html, both project pages and this page, at qyyyyy123.github.io/data-science-portfolio
  • Every internal link and image resolves — checked against the file tree, not eyeballed: 0 broken href, 0 broken src
  • Images display — all nine figures are committed in assets/img/, with intrinsic dimensions and alt text
  • Every figure caption names its axes and units — the standard the peer review set, applied to all six
  • Every external link points at a public repository, a specific commit, or a DOI
  • Layout holds at 500 px, 768 px and 1280 px — no horizontal page scroll; wide tables scroll inside their own container. Chrome on Windows will not open a 360 px window, so 500 px is the narrowest viewport that could be rendered directly; nothing in the stylesheet has a fixed pixel width, so narrower screens wrap rather than overflow.
  • Print stylesheet drops the navigation so the pages can be read as a PDF
  • Numbers on the site match the artifacts — every statistic quoted here is taken from the committed JSON/CSV files, and the report is generated from them

The site is plain HTML and one stylesheet: no build step, no JavaScript, no external CDN, so there is no runtime that can fail silently.
